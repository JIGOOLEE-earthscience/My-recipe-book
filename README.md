# 나만의 레시피북

휴대폰에서 유튜브 요리 영상 링크를 넣으면 Gemini가 영상을 보고 준비물·요리법으로 정리해 주는 개인 레시피 웹 앱. 단계를 누르면 그 장면이 바로 재생됨. PC·서버 없이 휴대폰만으로 씀.

## 지금 상태
- claude.ai 아티팩트 버전(프로토타입) 완성 → `prototype/`
- 휴대폰 전용 웹 앱 제작 예정 → `app/`
- 진행 상황: `docs/05_진행상황.md`

## 필요한 것
- 휴대폰 브라우저
- Gemini API 키(aistudio.google.com에서 발급). 앱 설정 화면에 입력하면 휴대폰에만 저장됨.

## 사용 방법
- 1단계 완료 후 이 칸에 채울 예정.
